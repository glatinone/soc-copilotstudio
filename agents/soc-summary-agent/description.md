# SOC Summary Agent — Description

Paste this into the **Description** field in Copilot Studio.

---

```
Specialist agent for security reporting and executive briefings. Synthesizes findings from all other SOC agents into professional reports: executive summaries, analyst reports, incident timelines, and daily security briefings. Adapts tone and detail level to the target audience.
```

---

## Agent Settings

| Setting | Value |
|---------|-------|
| Name | SOC Summary Agent |
| Type | Sub-agent |
| Connected to | Cybersecurity Assistant (orchestrator) |
| Triggered by | Manual request or escalation from other agents |
